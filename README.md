# ConceptBridge 概念桥

输入一个具体的研究难题，从另一个学科的文献里找出**结构相似**的机制，给出可迁移假设、差异说明和可回查的原文。

> 跨学科检索现在找的是同一个词。概念桥找的是同一个道理。

赛题归属：高级组主题 3「跨域知识探索 / **跨学科知识发现**」。

它不是论文摘要器，不是通用问答，也不是文献管理工具。一次查询返回一组跨域桥：左侧是源领域的机制，右侧是另一个领域里结构对得上的机制。

---

## 现在打开能看到什么

当前可运行语料是 500 篇 OpenAlex 论文、1394 条机制，覆盖材料、化学、生物、医学、计算机、物理。安装后，页面上的三个例子会各自展开不同的图：

| 查询 | 源领域 | 图上能看到的 |
|---|---|---|
| 锂枝晶抑制 | 材料科学 | 锂枝晶、锂金属电沉积、碳酸锂、BN 涂层隔膜，桥到另一领域 |
| 催化剂失活 | 材料科学 | 石墨结构与石墨烯载体上的催化活性，桥到另一领域 |
| 蛋白质折叠 | 生物学 | 膜、通道蛋白、锚定位点，桥到另一领域 |

每条桥包含结构分、语义分、领域距离、反琐碎惩罚、角色对齐、可迁移假设、差异和原文片段。引用按论文 ID 和字符偏移回查摘要。自动选源时，左侧最多保留 5 条词面最贴近查询的机制，所以三张图不会再铺成同一团。

假设文案在没有模型缓存时由规则模板生成。第一条桥是结构签名对上的结果，类比本身仍可能牵强，页面上的差异说明就是用来标出不能照搬的地方。

## 跑起来

需要 Python 3.11（由 uv 提供）和 Node.js 24。Windows 与 Linux 都用 `uv run task <cmd>`。

```bash
uv sync --extra analyze
uv run python scripts/ingest_corpus.py
```

两个终端：

```bash
uv run task dev
```

```bash
npm --prefix web ci
npm --prefix web run dev
```

浏览器打开 <http://127.0.0.1:5173/>。Vite 把 `/api/v1` 转到本机 8000。`DEMO_MODE` 默认关闭，装好索引后主查询走这 500 篇，`meta.stub` 为 false。

没有 Node 时，只起 API，打开 <http://127.0.0.1:8000/>。这是后端自带的单页（约 10.8 KB，无外部资源），能查、能看桥、假设、差异和引用，没有双域动画。

### 现场演示

```bash
uv run task demo
```

预检资产后以 `DEMO_MODE=1` 启动，只读 4 条冻结样例，不访问外网。地址同样是 <http://127.0.0.1:8000/>。

```bash
uv run task demo --corpus
```

用已安装的 500 篇语料，并设 `LLM_OFFLINE=1`，模型只读缓存。索引没装会直接拒绝启动。

`--fixtures` 和 `DEMO_MODE=1` 始终读 `fixtures/bridge.sample.json`，不会变成这 500 篇。

## 一次查询在做什么

1. 从摘要抽出机制四元组：主体、动作、客体、条件与结果，并带原文偏移。
2. 动作收进 12 类：inhibit、promote、transport、transform、recognize、amplify、stabilize、degrade、compete、isolate、trigger、regulate。
3. 候选按结构签名打分，语义相似度作软约束，跨领域加分，空条件、泛化动词和换皮同名会被反琐碎项压下去。
4. 返回最多 5 条目标领域不同于源领域的桥。

默认语义向量是哈希嵌入，用来让离线演示不下载模型。它不是 `multilingual-e5-large` 的结果。

## 评测

`eval/reports/latest.md` 来自闭集：30 条金标准正例材料化成的机制，加上 10 条负例。这不是 500 篇文献库上的检索指标。

| 配置 | P@5 | MRR@10 |
|---|---|---|
| A 纯语义 | 0.7667 | 0.3848 |
| B 加上结构签名 | 1.0000 | 0.9611 |
| C 再加领域距离 | 1.0000 | 0.9611 |
| D 完整公式 | 1.0000 | 0.9611 |

闭集里的目标全部跨领域，领域距离恒为 1，所以 B 和 C 的排序相同。没有模型缓存时，重排不改分数，D 与 C 相同。10 条负例上，关掉反琐碎的误报率是 0.4000，完整公式是 0.0000。

重新生成：`uv run task eval`。

## 边界

- 样板是材料/化学到生物/医学，以及算法/物理到生物。语料里有六个领域，不追求换一个学科就能用。
- 可运行的图是 500 篇、1394 条机制。采集器另有 1500 篇原文的记录；正式的「500 篇抽出至少 1200 条、schema 通过率 ≥98%、人工抽检 ≥80%」还没有作为达标证据关闭。这 1394 条里剔除过 42 条比较或描述性关系，独立人工审核仍未完成。
- 显式指定源领域时，仍会返回该领域的全部机制，左侧图会重新变大。
- 机制详情、邻域和健康检查与主查询读同一份快照。快照缺失时退回冻结样例。
