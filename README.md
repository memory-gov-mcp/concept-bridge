# ConceptBridge 概念桥

**输入一个具体的研究难题，从另一个学科的文献里找出「结构相似」的机制，返回可迁移假设、差异说明与可回查的原文。**

> 跨学科检索现在找的是同一个词。概念桥找的是同一个道理。

赛题归属：**高级组 · 主题 3「跨域知识探索」—— 跨学科知识发现**。

---

## 1. 问题：学科壁垒的实质是术语壁垒

锂枝晶是锂电池二十年没解决的问题。生物学里有一个每天都在运转的解法：细胞膜靠一层几十纳米的选择性屏障，让特定离子通过、把其余挡在外面。

这两件事在**结构上是同一件事**——一个选择性屏障在梯度下放行特定载流子。但它们的用词、尺度、期刊完全不重叠。做电池的人搜「锂枝晶」，永远搜不到细胞膜。

现有工具都答错了题：

| 做法 | 它回答的问题 | 漏在哪 |
|---|---|---|
| 关键词检索 | 哪篇论文**含有**这些词 | 只匹配词形，跨语言/跨领域同义全部失配 |
| 向量检索 / RAG | 哪段文字与我的**表述**相近 | 匹配用词相近，**同构但异词**的机制被系统性漏掉 |
| 领域知识图谱 | 实体间**已定义**的关系 | 需人工建本体，跨领域不通用 |

三者共享同一个隐含假设：**相似 = 文字相似**。只要相似度建在文本上，膜与枝晶之间的桥就永远搭不起来。

**概念桥回答的是第四个问题：哪个机制，和我的机制在结构上是同一类？**

## 2. 解法：把「机制」抽成可比较的对象

```
OpenAlex 论文（英文摘要）
   │ ① 抽取：LLM + JSON Schema 强校验
   ▼
机制四元组  主体 —动作→ 客体  +  条件/结果  +  原文证据偏移
   │ ② 算结构签名（不含任何文本特征）
   ▼
structure→transport→process | direct | neutral | 2 个条件
   │ ③ 跨域检索：候选召回 → 结构打分 → 反琐碎 → 重排
   ▼
跨域桥：源机制  ⇄  目标机制 + 假设 + 差异 + 引用
```

三个关键设计：

- **动作强制收进 12 类**（inhibit / promote / transport / transform / recognize / amplify / stabilize / degrade / compete / isolate / trigger / regulate）。允许无限细分就等于退化成自然语言，「结构相似」会变成主观判断。
- **反琐碎惩罚**：LLM 做跨域类比时绝大多数输出是「都需要能量输入」「都受环境影响」这类废话。系统命中泛化动词、空条件、同域换皮即重罚——**这是判断它是否真懂行的关键**。
- **每条结论必须挂 span**：假设与差异里引用的任何事实，都要能按字符偏移切回原文。没有出处的断言直接判失败。

## 3. 一次查询你会看到什么

输入「锂枝晶抑制」，返回的第一条桥：

| | 内容 |
|---|---|
| **源机制** | SEI 膜 —选择性输运→ 锂离子通量（structure→transport→process，direct，2 个条件） |
| **目标机制** | 细胞膜 —选择性输运→ 胞内离子稳态（生物学） |
| **对齐** | 主体↔主体（同为薄选择性屏障）· 客体↔客体（同为被调控的离子输运） |
| **可迁移假设** | 在 SEI 中接枝固定化磺酸根位点构建单离子导体通道，使 t⁺ 从 0.3 提升到 0.7 以上，预期枝晶成核过电位提高一倍 |
| **差异（不能照搬）** | 生物膜含主动转运泵，SEI 只有被动扩散；尺度差 3 个数量级，需考虑应力效应 |
| **引用** | 原文片段 + 论文 ID + 字符区间，点击高亮 |

界面是**双域图 + 桥动画**：左侧源领域机制成形，一条弧线飞到右侧目标领域，结构对齐的节点同步高亮，下方展开假设卡 / 差异卡 / 引用卡。支持键盘 `←/→` 一屏一屏讲，附带离线回放。

当前可运行语料：**500 篇 OpenAlex 论文、1394 条机制**，覆盖材料、化学、生物、医学、计算机、物理。三个预置例子（锂枝晶抑制 / 催化剂失活 / 蛋白质折叠）各自展开不同的图。

## 4. 凭什么说这不是 RAG

| 维度 | RAG / 语义检索 | 概念桥 |
|---|---|---|
| 检索单位 | 文本块 chunk | 机制四元组 |
| 相似度 | 向量余弦 | **结构签名匹配**（文本只作软约束） |
| 输出 | 原文摘录 / 摘要 | 可迁移假设 + 差异 + 逐条引用 |
| 失败模式 | 召回「用词像」的废话 | 由反琐碎惩罚显式压制 |

消融实验（把打分公式拆开跑）：

| 配置 | P@5 | MRR@10 |
|---|---|---|
| A 纯语义（= RAG baseline） | 0.7667 | 0.3848 |
| B + 结构签名 | **1.0000** | **0.9611** |
| C + 领域距离 | 1.0000 | 0.9611 |
| D 完整公式 | 1.0000 | 0.9611 |

**A→B 的增益就是「结构」这两个字值多少分。** 在 10 条「看起来像但实际不成立」的负例上，关掉反琐碎的误报率 0.4000，完整公式 0.0000。

⚠️ 诚实说明：以上是 **30 条金标准正例构成的闭集**上的结果，**不是 500 篇文献库上的检索指标**。闭集里目标全部跨领域，领域距离恒为 1，所以 B/C/D 排序相同。

## 7. 已知限制

- 样板是材料/化学 → 生物/医学、算法/物理 → 生物；语料含六个领域，但**不追求换个学科就能用**。
- 1394 条机制经过 Agent 抽查与定向核对（剔除 42 条比较/描述性关系、修正 14 条），**独立人工审核仍未完成**。
- 选源是词面匹配 + 中文术语表。词完全没命中语料时会静默回落到某个领域的机制（左侧图变大、与查询关系变弱）；词形变化未覆盖（`immunity` 命不中 `immune`）。
- 真正的跨语言检索应换多语种向量；当前默认哈希嵌入只为离线演示不下载模型。
- 显式指定源领域时仍会返回该领域全部机制，左侧图会变大。

## 8. 怎么运行

```bash
uv sync --extra analyze
uv run python scripts/ingest_corpus.py            # 安装 500 篇语料 → data/index/g-*
uv run task dev                                   # API :8000
npm --prefix web ci && npm --prefix web run dev   # 前端 :5173（Windows 用 npm.cmd）
```

只起后端也能看：<http://127.0.0.1:8000/> 是自带的单页界面（约 10.8 KB，无外部资源），能查、能看桥与引用，只是没有双域动画。

现场演示（断网安全）：`uv run task demo --corpus`；纯冻结样例：`uv run task demo`。

> 网络受限（PyPI / npm 的 https 不通）时改用明文镜像：
> `uv sync --extra analyze --default-index http://mirrors.aliyun.com/pypi/simple --allow-insecure-host mirrors.aliyun.com`
> `npm.cmd --prefix web install --no-package-lock --registry=http://registry.npmmirror.com`

工程细节（契约、数据格式、四人分工、任务卡）见 [AGENTS.md](AGENTS.md)；
产品叙事与答辩讲法（30 秒 / 3 分钟 / 10 分钟三套 + 最可能被问的 5 个问题）见 [docs/intro.md](docs/intro.md)；
