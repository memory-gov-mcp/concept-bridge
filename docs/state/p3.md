## 本次交付要点（给 P1/P2/P4 看的）

1. **`POST /api/v1/bridge/stream`** 已可用，SSE 帧序为
   `stage(recall) → stage(score) → stage(generate) → result → done`。
   P4 要做出"渐进呈现"就用它；不想处理流式就用同步 `/bridge`。
   **注意**：stage 里的 `progress` 只是节奏提示，不是真实百分比，不要显示成进度条。
2. **降级语义已经定死**，P2 不用管：
   - `stub=true`：还没接算法，返回 fixture
   - `degraded=true`：接了算法但超时/抛异常，返回 fixture 并把标记置上
   - 两者都**不会**返回 5xx 或空页
3. **`run_bridge()` 签名没变**，`match/pipeline.py` 一出现就自动接管，不需要通知任何人改代码。
4. **mypy 现在覆盖 `common/` + `api/`**。P2 落地 `match/` 后把路径加进
   `pyproject.toml` 的 `[tool.mypy] files`，别让新代码裸奔。
