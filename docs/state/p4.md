## T1 验收

- `npm --prefix web ci` 可从锁文件安装，`npm --prefix web run build` 构建成功。
- `npm --prefix web run dev:mock` 在 FastAPI 停止、浏览器阻断外部请求时返回 HTTP 200，显示 2 条桥与引用。Chrome 验证了短查询、空结果、重新查询和 390px 宽度。
- `uv run --no-sync task dev` 与 `npm --prefix web run dev` 联调，FastAPI 日志记录桥接请求 HTTP 200，结果为 2 条桥、`stub=false`。
- `uv run --no-sync task e2e` 通过 3 条演示查询。远端暂无 `develop`，本地分支从 `origin/main` 创建。

## T2–T7 验收

- `uv run --no-sync task check` → `[check] OK`（42 个 Python 测试及 TypeScript/ESLint）；`uv run --no-sync task e2e` → 3 条演示查询通过。

## 前端复审

- 接口与 Mock 验收覆盖异常响应、非法请求字段和网关超时。查询页可重试上次失败请求，输入校验和请求失败分别提示。
- 查询结果可定位对应的图谱，图谱与结果卡统一显示动作类别，原始动作词和引用原文保留。320px 查询页无横向溢出，调整窗口后保留图谱缩放比例。
- 键盘验收覆盖导航焦点、引用高亮、方向键翻屏和窄屏评测表横向滚动。评测页区分后端、Mock 和离线快照。
- `npm --prefix web test` → 23 个通过。生产构建、`uv run --no-sync task check`（42 个 Python 测试）及 `uv run --no-sync task e2e`（3 条演示查询）通过。本机 Chrome 复验动画约 1.80 秒，合成 200 节点图拖动 60.3 FPS，真实 API 查询 HTTP 200 返回 2 条桥。

## T4 技术复验

- 在 Chrome 和 Edge 分别验证真实 FastAPI、Mock、合成边界数据三种场景。鼠标点击及空格键高亮的内容逐字等于接口引用。验证了五项评分、0 和 1 的边界值、同卡多引用切换及不同卡片的高亮隔离。
- 合法 OpenAlex ID 生成对应文献链接，样例结果和非 OpenAlex ID 不生成链接。含 HTML 字符的引文保持纯文本，原始空白和偏移保留。
- 在 320px 视口向假设、差异和结果注入长连续英文标识符，修复前页面宽度达到 4,832px。修复后同一输入在两款浏览器均保持 320px。
- `npm --prefix web test` 24 个通过；`npm --prefix web run build` 成功；`uv run --no-sync task merge` 全绿。
- 技术复验覆盖功能正确性和布局。T4 仍需五名首次使用者的可读性评分，平均至少 4/5。
