## P1-T1 验收记录（2026-11-03）

命令均从仓库根执行。Windows 当前用户的全局 uv cache 无写权限，本次使用工作区缓存。

```powershell
$env:UV_CACHE_DIR = Join-Path $PWD 'data/.uv-cache'
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD = '1'
$env:PYTEST_ADDOPTS = '--basetemp=data/.pytest-tmp'
uv sync --extra analyze
uv run python -m conceptbridge.ingest.cli --limit 1500
uv run task check
uv run pytest tests/ingest -q -p pytest_cov --cov=conceptbridge.ingest --cov-report=term-missing --cov-fail-under=70
uv run task e2e
```

`domain_missing_rate=0.0`。材料、化学、生物、医学、计算机、物理各 250 篇。
独立回读确认 1500 个唯一 paper ID，全部有摘要、年份与领域。
`papers.jsonl` SHA-256 为 `9c9e5415b0ffe12c0dedd30d95f0a88ac732902169c0aaec0a5328b7df738a21`。

`uv run task check` 输出 `[check] OK`，60 个测试通过。采集测试 18 passed，覆盖率 91.06%，
摘要归一模块覆盖率 90%。`uv run task e2e` 输出 3 passed。
设置 `$env:DEMO_MODE='1'` 后重复采集命令成功，论文 SHA-256 相同，日志中无 HTTP 请求。
测试还覆盖页内剩余数据离线恢复、重复 ID、页请求失败后的断点保留及并发写拒绝。

失败记录共 8 项，包含 7 篇倒排摘要缺失位置的论文，以及早期 cursor 翻页的 401 历史。

## P1-T2 至 T6 代码与离线验收（2026-11-03）

用户要求本次继续完成 P1 代码并补齐设计，后续明确只先试跑 8 篇，核算用量后再决定扩量。
默认 limit=8、retries=0。公共网关传输层最多尝试 3 次，预检查将此项单独显示。

设计位于 `src/conceptbridge/extract/DESIGN.md`，操作与 P2 接口说明位于同目录 README.md。
实现包括版本化 prompt、草稿校验与签名推导、精确证据定位、概念/条件归一、成功任务缓存、
失败修复、并发锁、不可变运行目录、审核样本、数据清单与图谱导出。

本次真实预检查输出为 `papers=8 initial_requests_upper_bound=1 transport_attempts_upper_bound=3`、
`prompt_characters=11977 max_output_tokens_per_request=8192 retries=0 key_configured=False`。
字符数不等于 token 数，当前没有可据此计算的真实模型费用。
