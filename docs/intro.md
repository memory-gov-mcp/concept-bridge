# 概念桥 ConceptBridge · 项目介绍

> **一句话**：输入领域 A 的一个具体难题，从领域 B 的文献里检索**结构相似**的机制，
> 输出可迁移的假设、两者的差异，以及可点击溯源的原文出处。
>
> **更短的一句**：现在的跨学科检索找的是"同一个词"，我们要找的是"同一个道理"。
>
> 赛题归属：高级组 · 主题 3「跨域知识探索」→「跨学科知识发现」。

本文是**产品与技术叙事文档**，回答"为什么做、做成什么样、凭什么成立、边界在哪"。
工程规范、契约、分工、任务卡见 [AGENTS.md](../AGENTS.md)。

## 1. 要解决的问题

### 1.1 学科壁垒的实质是"术语壁垒"，不是"知识壁垒"

锂枝晶是锂电池领域二十年没解决的难题。生物学里有一个每天都在运转的解法：
细胞膜靠一层几十纳米的选择性屏障，让特定离子通过、把其余挡在外面，于是胞内浓度稳定。

这两件事在数学结构上是同一件事——**一个选择性屏障在梯度下放行特定载流子**。
但它们的用词、尺度、期刊、学者社群完全不重叠。任何做电池的人去搜"锂枝晶"，
永远搜不到细胞膜；去搜"选择性通透"，搜到的全是生物膜，与他的问题无关。

**知识是存在的，通路是不存在的。**

### 1.2 现有工具的三种做法，都答错了题

| 做法 | 代表 | 它回答的问题 | 漏在哪 |
|---|---|---|---|
| 关键词 / 布尔检索 | Web of Science、Scopus、知网 | "哪篇论文**含有**这些词" | 只匹配词形。跨语言、跨领域的同义与异义全部失配 |
| 向量语义检索（含 RAG） | 语义搜索、文献问答、综述助手 | "哪段文字与我的**表述**相近" | 匹配的是用词相近。**同构但异词**的机制被系统性漏掉 |
| 领域知识图谱 / 本体 | 各类 domain KG | "实体之间有什么**已定义**的关系" | 需要人工建本体，跨领域不通用，覆盖面极稀疏 |

三者共享同一个隐含假设：**相似 = 文字相似**。

而"细胞膜的选择性通透"与"SEI 膜的离子筛分"在字面上几乎没有交集。
只要相似度建在文本上，这条桥就永远搭不起来。

### 1.3 我们要回答的是第四个问题

> **哪个机制，和我的机制在结构上是同一类？**

不是"有没有相关文献"，不是"这段话像不像"，而是"这两个因果结构能不能对上，
对上了以后能迁移什么过来"。

## 2. 核心概念：机制同构

### 2.1 把"机制"抽成一个可比较的对象

一段摘要里真正有用的不是句子，是**机制**：谁，做了什么，在什么条件下，导致了什么。
我们把它抽成结构化的一条：

```
机制四元组  M = (S, A, O, C, R)
  S  主体（带概念类型）
  A  动作（带 12 类动作类别 + 极性）
  O  客体（带概念类型）
  C  条件集合（归一后的条件标签）
  R  因果形态（直接 / 中介 / 反馈 / 阈值）
```

每条机制都强制携带一段**原文证据 span**（字符偏移 + 原文片段），后面所有输出都必须能指回它。

### 2.2 结构签名：只有它才是"结构"

上面五个位置各自取值，就得到这张签名的六个维度：

| 维度 | 取值 | 例 |
|---|---|---|
| 主体类型 | 5 类：`structure` `process` `substance` `signal` `state` | 细胞膜 → `structure` |
| 动作类别 | **固定 12 类**：`inhibit` `promote` `transport` `transform` `recognize` `amplify` `stabilize` `degrade` `compete` `isolate` `trigger` `regulate` | 选择性输运 → `transport` |
| 客体类型 | 同 5 类 | 胞内离子稳态 → `process` |
| 因果形态 | `direct` `mediated` `feedback` `threshold` | `direct` |
| 极性 | `promote` `inhibit` `neutral` | `neutral` |
| 条件数 / 条件标签 / 元数 | 整数 / 归一标签集合 / 2–8 | 2 / `{concentration_gradient, membrane_potential}` / 2 |

动作类别**必须**落在这 12 类里，不许自由发挥。这是刻意的约束：
一旦允许无限细分的动词，签名就退化成自然语言，"结构相似"就成了主观判断，
既无法比较也无法评测。12 类是我们在**表达力**与**可比较性**之间选的支点。

### 2.3 同构的定义

两个机制**结构同构**，当且仅当：主体类型相容、动作类别相同、客体类型相容、
因果形态相同、极性相同、条件集合可对齐。

同构程度就是结构签名相似度：

```
struct_sim = 0.30 × 主体/客体类型匹配
           + 0.25 × 动作类别匹配
           + 0.15 × 因果形态匹配
           + 0.15 × 条件 Jaccard
           + 0.15 × 极性匹配
```

**注意：这个定义里没有任何一个字来自文本。** 文本只作为软约束参与排序，
不决定"像不像"。这是本项目与 RAG 最根本的分野。

## 3. 系统怎么工作

```
OpenAlex 论文库（亿级，CC0）
   │  ① 采集：摘要 + 领域标签
   ▼
论文集合
   │  ② 机制抽取：LLM + JSON Schema 强校验，每篇 1–5 条
   ▼
机制集合（结构化，带 evidence span）
   │  ③ 建图：概念为点，机制为边；概念归一 + 向量索引
   ▼
异构图谱
   │  ④ 查询：候选召回 → 结构打分 → 反琐碎 → 重排
   ▼
跨域桥（假设 + 差异 + 引用）→ 双域图谱可视化
```

四步各自的难点与对策：

| 步骤 | 难点 | 我们的对策 |
|---|---|---|
| ① 采集 | 摘要字段是倒排索引，不是文本 | 按词位置还原成连续文本；领域标签取 OpenAlex 的 topic 体系 |
| ② 抽取 | LLM 会编造、会漏字段、会自相矛盾 | JSON mode + Pydantic 强校验 + 失败重抽；**签名由代码从三元组推导，不许模型自由填**；`span` 必须能在摘要里按偏移切出来，切不出就判失败 |
| ③ 建图 | 同一概念有多种写法；跨域同名不同义 | 字符串规范化 + 别名合并 + **同名跨域强制拆分**（"膜"不能并入"细胞膜"） |
| ④ 匹配 | 结构对上但语义荒谬；找到的全是废话 | 语义作软约束；领域距离作加分；**反琐碎惩罚**压掉泛化类比 |

## 4. 走一遍完整例子

**输入**：`锂枝晶抑制`（材料科学）

### 第一步：抽出源机制

```
主体：SEI 膜                 （structure）
动作：选择性输运             （transport，polarity = neutral）
客体：锂离子通量             （process）
条件：浓度梯度、电场
结果：锂离子定向通过，溶剂与阴离子被阻挡，沉积趋于均匀
因果：direct      证据：摘要第 120–262 字符
```

### 第二步：算出签名

```
structure → transport → process | direct | neutral | 2 个条件
```

### 第三步：候选与打分

系统从**其它领域**召回 412 条候选，逐条打结构分。排在前面的两条：

| 候选 | 来源领域 | 结构分 | 语义分 | 领域距离 | 反琐碎 | 总分 |
|---|---|---|---|---|---|---|
| 细胞膜离子通道 → 胞内离子稳态 | 生物学 | 0.71 | 0.55 | 0.93 | 0 | **0.72** |
| 调节性 T 细胞 → 抑制过度免疫反应 | 生物学 | 0.62 | 0.48 | 0.88 | 0.1 | **0.61** |

第一条的算法：

```
0.45 × 0.71 = 0.3195
0.30 × 0.55 = 0.1650
0.25 × 0.93 = 0.2325
- 0.35 × 0.00 = 0
                ------
                0.717  →  0.72
```

### 第四步：输出

```
【桥】材料科学 · SEI 膜  ⇄  生物学 · 细胞膜离子通道

可迁移假设
  在 SEI 中接枝固定化磺酸根位点构建单离子导体通道，
  使锂离子迁移数 t+ 从 0.3 提升至 0.7 以上，
  预期将枝晶成核过电位提高一倍以上。

差异（为什么不能直接照搬）
  · 生物膜含主动转运泵，可逆电化学梯度耗能输运；SEI 只有被动扩散，无法主动富集
  · 生物膜厚约 5 nm 且具流动性；SEI 为 10–50 nm 的无机/有机复合层，力学约束显著

对齐
  主体：SEI 膜 ⇄ 细胞膜          （同为薄选择性屏障）
  客体：锂离子通量 ⇄ 胞内离子稳态 （同为被选择性调控的离子输运）

引用
  Plasma membrane ion channels selectively conduct specific ions down their
  electrochemical gradient while excluding others …  [原文高亮]
```

**假设必须是可验证的**：上例给了迁移数目标、过电位倍数——审稿人或评委能据此设计实验。
"两个领域可以互相借鉴"这种话在我们这里算输出失败。

### 为什么不是另一篇讲枝晶的论文

同领域论文的 `domain_distance` 接近 0，会被压下去。这是刻意的：
我们要的是**跨域**桥，不是"把同一个领域里你已经知道的结论再念一遍"。
系统里 `target_domain == source.domain` 的结果会被校验器直接丢弃。

## 5. 反琐碎：这个系统最容易崩的地方

LLM 做跨域类比时，绝大多数输出是废话：

> "两者都需要能量输入"、"都受环境影响"、"都是自组织系统"、"存在正反馈"

这些**不是错的**，但它们没有任何可迁移信息。如果不处理，检索结果会被这类东西塞满，
P@5 全是垃圾，现场任何一个人问一句"所以呢"就崩了。

所以系统有一条硬性惩罚项，命中任一条件即 `triviality = 1`，直接扣掉 0.35 分：

1. `condition_count == 0` —— 没有前提的机制等于没机制
2. `arity < 2` —— 只有单个实体的"机制"不是机制
3. 动作命中泛化词表：影响 / 促进 / 相关 / 参与 / 涉及 / 存在
4. 源与目标概念的名字或向量相似度 > 0.95 —— 这是同一领域换皮，不是跨域

**这条惩罚项比任何正向打分都重要。** 它决定的是"系统知不知道什么是坏答案"，
而评委判断一个 AI 项目是否真懂行，靠的往往正是这一点。

## 6. 凭什么说这不是 RAG

三条硬差异，每一条都可以被检查：

| 维度 | RAG / 语义检索 | 概念桥 |
|---|---|---|
| **检索单位** | 文本块（chunk） | 机制四元组（结构化对象） |
| **相似度定义** | 向量余弦 | 结构签名匹配（文本只作软约束） |
| **输出** | 原文摘录 / 摘要 | 可迁移假设 + 差异说明 + 逐条引用 |
| **典型失败** | 召回"用词像"的废话段落 | 由反琐碎惩罚显式压制 |

**而且我们有消融表。** 把打分公式拆成四段分别跑：

| 配置 | 结构签名 | 领域距离 | LLM 重排 | P@5 | MRR@10 |
|---|---|---|---|---|---|
| A 纯语义（等价于 RAG baseline） | ✗ | ✗ | ✗ | 0.7667 | 0.3848 |
| B + 结构签名 | ✓ | ✗ | ✗ | 1.0000 | 0.9611 |
| C + 领域距离 | ✓ | ✓ | ✗ | 1.0000 | 0.9611 |
| D 完整 | ✓ | ✓ | ✓ | 1.0000 | 0.9611 |

A 到 B 的差值，就是这张闭集上结构签名带来的增益。原文在 `eval/reports/latest.md`。

这张表的语料是 30 条金标准正例材料化成的机制，不是 500 篇文献库。闭集目标全部跨领域，领域距离恒为 1，所以 B 与 C 排序相同。没有模型缓存时重排不改分数，D 与 C 相同。10 条负例上，关掉反琐碎的误报率是 0.4000，完整公式是 0.0000。

## 7. 为什么这件事现在才做得到

三件事同时成立，窗口才打开：

1. **结构化抽取变可靠了。** JSON mode + schema 校验 + 失败重抽，让"从摘要里稳定抽出机制"
   从研究课题变成工程问题。两年前这需要人工标注或训练专用模型。
2. **多语种向量**让"跨语言"不再是独立难题，中文查询可以直接落在英文摘要上。
3. **开放学术数据成规模。** OpenAlex 以 CC0 开放亿级论文的元数据与摘要，
   领域体系现成，不用自己建本体。

**推论**：这个项目的护城河不在模型，在**机制层的表示设计与结构匹配的打分设计**。
这也是为什么我们的技术叙事落在这里，而不是"我们微调了一个模型"。

## 8. 它不是什么（边界）

明确划界，避免被误判成另一个东西：

- **不是文献综述助手。** 不做"帮我总结这 20 篇"，做"帮我从别的领域找一条可迁移的机制"。
- **不是通用问答。** 一次查询一次结构化输出，不做多轮对话。
- **不是知识图谱可视化工具。** 图谱是解释"为什么这两条能对上"的手段，不是产品目的。
- **不替代同行评审。** 输出是**待验证假设**，不是结论。系统显式给出 `differences`，
  正是为了抑制"过度迁移"——告诉用户哪里不能照搬。
- **不做模型训练。** 本赛制下性价比极低，且无法形成可解释的技术叙事。

## 11. 三种时长的讲法

### 30 秒（电梯）

> 跨学科检索现在只能找"同一个词"，但很多难题在别的学科已经用"同一个道理"解决过。
> 我们把论文里的机制抽成结构化签名，用**结构相似**而不是文字相似去跨域检索，
> 输出可验证的迁移假设和原文出处。比如锂枝晶问题，它找到的是细胞膜的选择性通透。

### 3 分钟（答辩）

按 [AGENTS.md §16](../AGENTS.md) 的脚本走：痛点 20 秒 → 输入查询 20 秒 → 源机制成形 20 秒
→ **桥动画 30 秒（全场唯一的"哇"）** → 假设与差异 30 秒 → 第二个例子 30 秒
→ 消融表 20 秒 → 价值与边界 10 秒。

### 10 分钟（深度交流）

本文第 1–6 节，重点讲三件事：为什么"文字相似"必然失败、结构签名怎么定义、
反琐碎惩罚为什么比正向打分更重要。

## 12. 最可能被问的五个问题

**Q1：这不就是 RAG 吗？**
检索单位不同（机制 vs 文本块）、相似度定义不同（结构签名 vs 向量余弦）、输出不同
（假设 + 差异 + 引用 vs 摘要）。并且我们有消融表：把结构项去掉会掉多少分，当场能看。

**Q2：跨域类比不是很容易胡说吗？**
是。所以我们把"防胡说"做成了系统的一等公民：动作类别强制 12 类、条件必须非空、
泛化动词入黑名单、同域结果直接丢弃、每条结论必须挂可点击的原文 span。
现场可以演示一条**被惩罚项压下去的废话桥**。

**Q3：怎么证明"找对了"？**
30 对人工标注的正例（跨域、写明为什么同构）+ 10 对"看起来像但实际不成立"的负例，
报 P@5 与 MRR，并做四段消融。标注由三人独立打分并报一致性系数。

**Q4：只做三个领域，能推广吗？**
方法不依赖领域，依赖的是 5 类概念类型 + 12 类动作这套轻量本体。换领域只需换语料，
不需要重建本体——这正是它相对于传统知识图谱的地方。当前范围收窄是为了把 demo 做扎实，
不是为了方法本身。

**Q5：LLM 抽错了怎么办？**
三道闸：JSON schema 严格校验（含内部一致性，如签名必须与三元组一致）、
失败重抽两次、`span` 必须能在原文按偏移切出来对得上。
抽错的样本会被判失败而不是静默入库；错样本落盘，可统计错误率。

## 13. 名词表

| 术语 | 含义 |
|---|---|
| **机制四元组** | 系统的最小单位：主体 + 动作 + 客体 + 条件/结果，带原文证据 |
| **结构签名** | 机制的六个结构维度取值，用于跨域比较；不含任何文本特征 |
| **桥（bridge）** | 一条跨域匹配结果，含目标机制、分数、对齐、假设、差异、引用 |
| **对齐（alignment）** | 源机制的哪个角色对应目标机制的哪个角色，前端据此做高亮 |
| **领域距离** | 两个领域在主题体系中的距离，同域为 0，跨域加分 |
| **反琐碎惩罚** | 对泛化/无语义迁移价值的类比施加的惩罚项 |
| **span** | 论文原文的一段连续字符区间，所有结论必须可溯源到它 |
| **P@5 / MRR@10** | 检索评测指标：前 5 条命中率 / 首个正确结果的平均倒数排名 |
